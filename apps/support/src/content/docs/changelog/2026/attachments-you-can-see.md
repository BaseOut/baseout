A backup has always held your attachments. Finding one meant knowing which record it hung off, opening
that record, and looking. That is a reasonable way to check one file and a poor way to answer "is this
image in the backup at all".

## A library, not a column

Attachments are their own section now. Every file across every base you have connected is in one
list, with a thumbnail, the field it came from and the record it belongs to. It switches between a
table and a gallery, and the choice stays where you left it.

## Grouped by where it came from

Files group by base, by table and by field, because those are the three questions people ask of a
file they are looking for. They do not group by record: a record with four screenshots would become
four groups of one, which is a list of records wearing a list of files as a costume.

## The same drawer as everywhere else

Opening a file opens the drawer the rest of the app uses, so what you learned in Data and Schema
works here without being learned again. From a comment thread, the attachment opens the file itself
rather than the comment that mentions it.
