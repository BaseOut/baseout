---
title: Comments from every base, in one stream
description: Comments left across your bases now read as one list you can filter, and a thread opens beside the record it belongs to instead of in a page of its own.
lastUpdated: 2026-07-29
---

Comments were the part of a base that a backup captured and nothing showed. They existed in the
data and had no surface, so the only way to read one was to restore it.

## One list across bases

There is a comments section now, on the same grid the rest of the app uses. It reads across every
base you have connected, so a question asked in one and answered in another is two rows in one list
rather than two searches.

## A name where there is a name

An author is shown as a name when the platform gives us one and as an address when it does not. The
initials chip appears only in the first case: initials built out of an email address are a guess
dressed as an identity.

## The thread sits beside the record

Opening a comment opens the record panel with the thread in it, so the discussion and the row it is
about are on screen together. Records can also be filtered by whether they carry comments at all,
which is the fastest way to find the parts of a base people actually talk about.
