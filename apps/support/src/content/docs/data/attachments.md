description: The files your backups already hold, as a browsable library.

The Attachments tab lists every file captured by your backups, as a table or as a gallery, with
filters on where a file came from and how large it is. Each file can be traced back to the base,
table, field and record it belongs to.

This page will cover finding a file, what the size and format markers mean, and when a file can be
downloaded from Baseout versus fetched from your own storage.

## Questions this page will answer

- How do I find one specific file?
- What does grouping by base, table or field do?
- Why can I download some files and not others?
- Does Baseout store a second copy of my attachments?
- Why is there no "attached on" date?
